# cmd-typing-test
Basic CLI typing test that displays WPM, KPM, accuracy, time, no. of words and keys pressed.

## Features
Asks for number of words to be on the test.
Random words from wordlist.txt, can be interchanged for a different wordlist.txt file.
Displays, Words Per Minute, Keys Per Minute, Accuracy(%), Time taken, Total number of words and keys.
Tracks number of mistakes.


## Build
Requires c++ compiler, windows for key codes to work.

In g++: 
```cmd
g++ main.cpp input.cpp interface.cpp -o typing-test.exe
```
then run typing-test.exe

# Working
Initializes a vector of strings corresponding to all the words in the word list at first, also creates an engine structured data object, it is a struct that contains the default engine and a uniform distribution range from std::random, it is then seeded with the epoch time at that instant. The vector initialization function can be called after the wordlist has changed such that the wordlist can be swapped or modified while running, feature not implemented yet though.
The wordlist.txt file has to be in src folder.

Has a main loop that takes in an integer input for the number of words to be tested on, it then runs the game loop.


The game loop is split into 2 phases, reading and processing. The reading part uses functions from conio.h, to read input continuously and checks for valid input through key code ranges (windows). The time system is facilitated through std::chrono, time is only counted from when the first valid input is given.

Then once a valid input is received the loop moves onto processing phase where a switch-case block for a function that returns enumeration states. The cases for each enum state is defined; match, miss and end.
The sentences are generated by choosing random indexes corresponding to words in the wordlist, and splicing them together in a single string, same string that is displayed on screen.


User friendly interface added, using ANSI escape sequences to "clear" CLI screen.

Main Menu -> Word Count Menu -> Typing Test -> Result Screen -> Main Menu ...


Each character typed in is checked against whatever index in the string the player is at currently, prevents mistypes from appearing on screen and disallows continuation until the character matches.


Wherever the Random Engine Struct or wordlist vector of strings is used, it is referenced directly so as to not create copies.
